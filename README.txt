CodeBox

Dateien:
- index.html
- manifest.json
- sw.js
- icons/

Für eine installierbare PWA muss die App über HTTPS bereitgestellt werden, z. B. über GitHub Pages.
Die Barcode-Sammlungen werden lokal im Browser gespeichert. Es gibt kein Benutzerkonto und kein Backend.

Funktionen:
- Barcode erstellen
- Speichern
- Suchen
- Sortieren
- Kategorien + Filter
- Bearbeiten / Löschen
- Export / Import von Sammlungen
- Dubletten-Schutz
- PNG-Export
- Drucken
- PWA-Installation
