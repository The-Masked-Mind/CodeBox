CodeBox v3.5.0

Öffentlicher Katalog: catalog.json muss im selben GitHub-Ordner wie index.html liegen.
In der App: Sammlung > Öffentlicher Katalog > Katalog verwalten.
Eine lokale Kategorie zu einer öffentlichen Sammlung übernehmen, bearbeiten, catalog.json exportieren und diese Datei bei GitHub ersetzen.
Dieser Entwurf ist lokal und KEINE Online-Verwaltung mit Login. Jeder Nutzer kann lokal einen Entwurf erstellen; nur wer Schreibzugriff auf das GitHub-Repository hat, kann ihn veröffentlichen.
Öffentliche Daten sind für alle einsehbar; keine internen oder vertraulichen Inhalte veröffentlichen.
Bestehende private Sammlungen bleiben im localStorage.
